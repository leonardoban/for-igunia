# For Igunia — My Lunea

A romantic, responsive, single-page website made with plain HTML/CSS/JavaScript. No build tools or dependencies.

## Add your own music
1. Put your MP3 file in the `music` folder.
2. Rename it to `our-song.mp3`.
3. Keep the path exactly `music/our-song.mp3`.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository (for example `for-igunia`).
2. Upload `index.html`, `README.md`, and the `music` folder (including your MP3).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. The URL will look like:
   `https://YOUR-USERNAME.github.io/for-igunia/`

## Personalize before sending
- The page is written in English for Igunia.
- Review the poem and wording so it sounds like you.
- The NO button grows the YES button after clicks, but the page also explicitly says there is no pressure and she can take her time.
- The mini-games are local browser interactions; no data is collected or sent anywhere.
